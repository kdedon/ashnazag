# A/UX system calls used by the Mac environment

Numbers and names come from the kernel `sysent` table in `/unix` (0x11005f84; 8-byte entries: arg count, flags, handler). Socket calls (70–93) are `netdown` stubs in `sysent` until the network module loads. Their names come from the `Patch.067C` stub functions; `*` marks names inferred from 4.2BSD argument counts.

Trap: `0` means `trap #0` with arguments on the stack (SVR2 style). `15` means `trap #15` with arguments in registers a0, d1, a1, d2, a2 (BSD style). The number is in d0 either way.

Used by: P = `Patch.067C`, c = `libc1_s`, m = `libmac1_s`, s = `startmac`, C = `CommandShell`, l = `launch`, f = `setfile`, o = `cmdo`, L = `Login`, M = `StartMonitor`.

Generated by `tools/coffscan.py` (direct traps) and `tools/callargs.py` (calls through `syscall()`).
